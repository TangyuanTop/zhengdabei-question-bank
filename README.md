> 非官方资料。题目与答案整理自网络流传的历年题库，答案可信度已在表中标注，请以教材和官方考纲为准。

## 刷题页功能

- 按章节、题型筛选，下拉里带题量
- 顺序练习 / 随机打乱 / 只刷错题 / 只刷标记题
- 模拟卷 85 题：按真实卷面比例抽题（单选 51 + 多选 25 + 判断 9），每次抽题不同
- 快捷键：`A`–`E` 选选项，`Enter` 提交或下一题，`←` `→` 翻页，空格看答案
- 错题和标记存在浏览器 localStorage，关页面不丢；换浏览器或清缓存会重置

## 答案可信度

表格中的「答案可信度」一列是这份材料最该先看的东西：

| 标记 | 数量 | 含义 |
| --- | ---: | --- |
| 已核对 | 8 | 原题库答案有误，按公式或定义重新核算过，理由写在「备注」 |
| 高 | 156 | 多个独立来源答案一致 |
| 中 | 153 | 两个来源一致 |
| 单源 | 509 | 只有一个来源，没有第二份可对照 |
| 有争议 | 7 | 来源之间答案冲突，保留了最可能的一个，**建议回教材确认** |

`单源` 占六成，是原始素材的限制：很多题在所有题库文件里只出现过一次，没有交叉验证的机会。**没有逐题解析**——原始题库里「试题解析」基本都是空的，这里没有编造解析。

## 仓库结构

```
成果/正大杯网考题库精编/     最终成品（HTML / XLSX / CSV / 说明）
tools/                      数据清洗与构建脚本（Python）
README.md
```

`tools/` 里是实际用过的处理流程，主要有：

| 脚本 | 作用 |
| --- | --- |
| `dump_docx.py` / `extract_xlsx.py` / `pdf_probe.py` | 从 docx / xlsx / pdf 原始文件抽取纯文本 |
| `parse_bank*.py` | 从纯文本里切分题干、选项、答案 |
| `canon.py` / `finalize.py` / `build_final.py` | 按**选项文字**对齐同题、投票定答案、分章 |
| `build_quiz.py` / `export.py` | 生成刷题页与 XLSX / CSV |
| `audit.py` / `trust.py` / `quality_v5.py` | 抽检、可信度评级、质量核查 |

这些脚本面向本地的原始题库文件（`work/` 下的中间 JSON），**原始素材未随仓库分发**（涉及第三方版权，且体积约 170 MB），因此脚本不能开箱直接跑通，仅作为处理过程的留档。

## 处理时踩过的坑

- 同一道题在不同题库里**选项顺序被调换**过，答案字母不能直接比对；合并时按选项文字对齐，再投票定答案。
- 多份文件其实是同一份题库的复制件，投票前按内容指纹去重，避免「复制得多就赢」。
- 题干里混入的答案字母、解析残段做了清洗；个别题干本身有排版损伤（原文件公式丢失），这类题尽量剔除，但可能仍有残留。
- 题库中的「判断题」在原文件里常与单选题混排，靠选项形态和答案位数区分。
