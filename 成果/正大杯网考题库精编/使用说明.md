# 正大杯网考题库 · 精编版

把工作区里散落的十几份题库（不同届、不同排版、大量互相复制的副本）合并、去重、按本科考纲重新分章后的成品。

## 文件

| 文件 | 用途 |
| --- | --- |
| `刷题自测.html` | 双击用浏览器打开即可刷题，离线可用，不需要联网、不需要装任何东西 |
| `正大杯网考题库_精编版.xlsx` | 可筛选、可排序的题库表格，含三张表：题库 / 章节统计 / 知识点清单 |
| `题库_全量.csv` | 同样的内容，纯文本格式，方便导入 Anki、问卷系统或其他工具 |

## 刷题页怎么用

打开 `刷题自测.html` 后：

- **章节**：按本科考纲 10 章 + 2 个附录筛选，下拉里带题量
- **题型**：单选 / 多选 / 判断
- **模式**：顺序练习、随机打乱、只刷错题、只刷标记题
- **模拟卷 85 题**：按真实卷面比例抽题（单选 51 + 多选 25 + 判断 9），每次抽的都不一样

快捷键：`A`–`E` 选选项，`Enter` 提交或跳到下一题，`←` `→` 翻页，空格看答案。

错题和标记存在浏览器本地（localStorage），关掉页面也不会丢；换浏览器或清缓存会重置。

## 用之前值得知道的两件事

**一、答案的可靠性不是整齐划一的。** 表格里“可信度”一列：

- `已核对`：8 道。原题库答案有错，我按公式或定义重新核算过，并在“备注”写了理由。
- `高`：多个独立来源一致。
- `中`：两个来源一致。
- `单源`：只有一个来源，没有第二份可以对照。
- `有争议`：7 道。来源之间答案打架，我留了最可能的一个，但**建议回教材确认**，别直接背。

`单源` 的题占了六成，这是原始素材的限制——很多题在所有题库文件里只出现过一次，没有交叉验证的机会。做题时如果觉得答案别扭，以教材为准。

**二、没有逐题解析。** 原始题库里基本没有解析（大部分文件里“试题解析”后面是空的），我没有替你编解析——编出来的东西看着像真的，反而更危险。这份材料适合“刷题 + 定位薄弱章节”，定位到之后回教材补，比背题有效。

## 已知的处理取舍

- 同一道题在不同题库里选项顺序被调换过，答案字母不能直接比对。合并时按**选项文字**对齐，再投票定答案。
- 多份文件其实是同一份题库的复制件（内容完全一致），投票前按内容指纹去重，避免“复制得多就赢”。
- 题干里混入的答案字母、解析残段做了清洗；个别题干本身有排版损伤（例如原文件里公式丢失），这类题已尽量剔除，但可能仍有残留。
